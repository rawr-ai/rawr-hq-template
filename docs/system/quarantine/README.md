# System Quarantine

This directory contains system docs that were too likely to be mistaken for current target architecture.

The files are preserved intact for provenance and future rewrite work. They are not active system authority.

Use the canonical Habitat architecture and runtime realization specifications
for migration planning:

- `docs/system/HABITAT_ARCHITECTURE.md`
- `docs/system/HABITAT_RUNTIME_REALIZATION.md`

After the migration, decide which system docs should be rebuilt as durable subsystem references.
