# Runtime Observation Owner

Keep this package-less TypeScript owner downstream and non-authorizing. Its sole
private edge is definition. SDK composition supplies finite selected seed data;
owners publish bounded definition records. Catalog includes all minimum sections
without implying that unobserved execution, mounts or finalization occurred.

Use closed per-kind projection schemas, detached immutable snapshots and one
bounded process-local history. Omit unsupported payloads without traversing or
stringifying them. Native telemetry sink failures never replace product results.
No generic event registry, lifecycle controller, resource acquisition, retry
queue, global state, raw error export or observation-selected policy belongs here.
