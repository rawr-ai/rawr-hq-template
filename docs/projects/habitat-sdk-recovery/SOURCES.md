# SDK Assessment Source Register

This is the canonical provenance register for the September 15 SDK assessment,
not a source of architecture or execution authority. The
[current assessment](assessment.md) owns the synthesis; the
[design philosophy](../../system/HABITAT_DESIGN_PHILOSOPHY.md) owns the agreed
governing intent.

## Preservation Rules

Thirteen source documents are retained under `resources/research/`. Their
narrative is preserved with an explicit evidence-only header. Links to retained
documents and current Habitat files are normalized; references to material not
in this repository are retained as provenance text rather than broken local
links. Markdown hard breaks in the earlier authoring proposal use backslashes
instead of trailing spaces, preserving their rendered meaning. Source SHA-256
values below identify the original files before these presentation changes and
header insertion, not the transformed copies.

These are dated evidence, proposals, and selected response extracts. Their
instructions and historical completion/pending claims are not active guidance.
The current assessment states what is superseded and what remains open. A
source's use of words such as "approved" or "next" describes its original
context, not fresh authorization from this consolidation.

## What Is Not Claimed

Raw conversation exports, every probe script, terminal logs, and hosted provider
receipts are not imported by this documentation pass. External source locations
inside the evidence remain provenance pointers, not required checkout paths or
newly run verification. The retained findings and commands preserve the audit's
reasoning, but this is not a hermetic reproduction bundle.

No historical frame has been fully reconstructed, no relevant skill has been
built from those conversations, and no SDK repair or provider integration is
implemented by importing these documents. See [triage](triage.md) for the
explicitly deferred next investigation and naming follow-up.
