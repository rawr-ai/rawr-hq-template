# ROADMAP

## Current Focus

- Preserve the accepted Habitat platform, Rawr product and Marketplace content
  boundaries and the released SDK/CLI foundation.
- Use the [reviewed realignment](projects/habitat-runtime-realignment/WORKSTREAM.md)
  and its admission condition to resume the [active runtime change](../openspec/changes/realize-app-runtime-spine/tasks.md)
  with corrected cold composition before live provisioning.

## Near-Term Milestones

1. Preserve named instance meaning, selected-process configuration and complete
   service construction references through one cold semantic pipeline.
2. Realize native resource lifetime, service binding, execution, mounting and
   observation; prove Habitat self-hosting and real Oclif/server/async/web hosts.
3. Release accepted SDK/CLI capability and issue independent consumer handoffs.
   Consumer migration and product acceptance are not implied by platform tests.

## Later (Parked / Future)

- Semantic ledger, temporal inquiry and later Rawr transfers have independent
  [capability gates](../openspec/changes/realize-app-runtime-spine/deferred-capabilities.md),
  not a global Fluree prerequisite.
- Native agent/OpenShell and desktop hosts retain independent qualification
  and integration under D-4. Their authoring/executable faces remain part of
  the active runtime, not deferred empty interfaces.
- Persisted observability integrations and deployment tooling extend the
  runtime's identity, observation and cold-handoff contracts; neither is claimed
  complete by this runtime workstream.
- External workspace plugin source locking after external sources are introduced;
  predecessor product-specific state names are not target platform authority.
- Marketplace/library workflows beyond local-first baseline.
- LLM-judge security layer beyond deterministic checks.
