# Development Service

Own the four repository, stack and worktree operation contracts. Inherit the
service router and select complete service@4 law. Consumers use only `./client`.

Native Effect operations consume ready filesystem/path and child-process
resources. No provider construction, service-side Effect terminal, private
process runtime, observability port or synthetic invocation identity belongs
here. Each module curates only the capabilities its operations need.

Git update is fast-forward-only and does not maintain Graphite ancestry. Stack
drain requests one native asynchronous merge; it never promises completion or
sweeps branches. Cleanup removes only explicitly admitted worktrees through Git.
Scratch admission observes caller-selected files, never personal directory or
filename conventions. Failed admission performs no domain mutation; command
failures report the actual attempted prefix without claiming rollback.

Run the owning Nx check and native behavior tests. Tests may own disposable Git
repositories and scoped child processes, never mutate the development checkout
or present a scripted executable as native Graphite acceptance.
