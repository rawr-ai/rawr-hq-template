# Provider

`provider` is one concrete realization of a parent resource contract. Its
enforced packet closes each provider package around a public `index.ts`, typed
project boundary, vendor-specific TypeScript implementation, and colocated
behavior proof.

The provider implements the mechanics for acquiring, using, and releasing its
capability. The application owns provider and lifetime selection; runtime owns
executing those mechanics and scoping the realized capability. Product policy
and service orchestration do not move into the provider merely because they
call it.
