# Grit Pattern Frame

> **Activation:** None. This lowercase `skill.md` is an unregistered design
> seed. Executable Grit authority remains in adjacent `pattern.md` packets.

## Frame

A Grit pattern names a relation in source code. It is valuable when the
relation is structural enough to recognize from syntax and meaningful enough
to prevent a recurring ownership, direction, or boundary defect.

The pattern is not a text search wearing an architectural name. Its helpers
should expose the semantic predicates that make the policy understandable:
which owner is in view, which edge is allowed, which boundary is crossed, and
which relation is missing.

## Gradient

Good source law narrows possibility through positive relationships. It favors
stable kinds and dependency direction over exact message text, current
filenames, product inventories, or migration residue. Named helpers carry
short comments because their purpose is the policy relation, not the parser
mechanics.

Grit complements rather than duplicates:

- `structure.toml` owns filesystem geometry.
- TypeBox and TypeScript own schema and type authority.
- Tests own state transitions and observable behavior.
- Review owns whether the encoded relation still reflects the architecture.

A passing pattern proves only the relation it can observe. It cannot establish
runtime behavior, module resolution, security, or lifecycle outcomes by
implication.
