# Agent Router

`agent-router` is the lightweight `AGENTS.md` document kind. Every admitted
package and service-module boundary owns one instance that locates an operator
inside that component and explains its product purpose, jurisdiction, behavior,
important concepts and entities, boundaries, flow, interfaces, routes, and
local validation. It is not architecture authority, project memory, a
target-file inventory, code narration, or a replacement for a complete
conceptual document.

This generic packet owns the document's positive Markdown anchors and the
syntax of one non-self relative `AGENTS.md` route. The RAWR repository niche
separately selects package roots and every direct standalone or API-embedded
service module directory, rather than one-off names or every internal Nx
project. That cross-kind relation may inspect open owner roots without
acquiring their topology; dotted module directory names remain covered even
when another topology law rejects their source placement.

The source-shape law rejects bare self-links, scheme and absolute destinations,
anchors, and non-`AGENTS.md` documents. It does not resolve `..`, prove that a
target exists, or prove that a path remains inside the repository; static link
audit and human review own resolution, escape detection, and conceptual
authority. Authored edges use standard Markdown so Obsidian and Foam can derive
backlinks without generated backlink lists or ambiguous short wikilinks. Human
review also owns whether prose explains why the component exists, remains
genuinely local, and avoids duplicating code or JSDoc.
