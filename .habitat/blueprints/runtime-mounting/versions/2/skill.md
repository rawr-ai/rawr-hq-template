# Runtime Mounting Owner

This private package-less owner consumes definition, process-runtime and
harnesses contracts. It claims one exact mount-ready process, invokes the
selected native descriptors in order, and creates private StartedHarness
records only after native success. It never re-derives, compiles, provisions,
binds, lowers or projects read models.

Finalization closes admission synchronously and shares one promise. Settle the
successful native prefix in reverse order, then stop the process. A native
owner settles partial mount cleanup before rejecting and includes active
health probes in native stop settlement. A waitForNativeStop deadline records
pending work without force or early provider release. Preserve the original
mount failure across rollback failures.

Explicit per-kind health queries and native reports are process-local evidence,
not a poller or controller. Required resources gate mounting; unknown, missing
and rejected evidence never passes readiness. No-op not-applicable evidence is
neutral, not invented passing native health. Observation uses the supplied
definition port and cannot replace outcomes. Source law checks owner imports;
types, behavior, cache and installed native integration prove their own bounds.
