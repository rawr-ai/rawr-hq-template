test, task count or receipt. Selected blueprint versions remain immutable
definition closures; a successor changes current selection without rewriting
its predecessors. Public exports and real ownership/dependency boundaries are
contracts, unlike incidental private filenames.

implementations are behavioral evidence, never Habitat source authority.
