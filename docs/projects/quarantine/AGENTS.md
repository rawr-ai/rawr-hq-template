# Project Quarantine Router

## Purpose

- Preserve displaced initiative material so past decisions remain traceable
  without reopening or rescheduling the recorded work.

## Scope

- Applies only to `docs/projects/quarantine/**`.

## Boundaries

- Material here is project-history provenance only; it is not active project authority.
- Quarantined packets cannot create work, sequencing, acceptance, or implementation obligations.

## Behavior

- Project-history records can supply provenance for a current decision only
  after the relevant fact is checked and accepted into an active owner.

## Concepts

- A **project-history record** describes a former initiative state. An
  **accepted fact** is historical evidence explicitly adopted by current
  project or canonical authority.

## Flow

- Read inward only to recover historical decisions or evidence.
- Restate any reclaimed fact in an active project or canonical document before relying on it.

## Interfaces

- Quarantined packets are provenance inputs; active project documents and
  canonical gateways are the only interfaces that can create present work.

## Routing

- Return to the [docs router](../../AGENTS.md) for current project authority.

## Validation

- Preserve the quarantine marker, required headings, and resolving router edge.
- Treat commands found below this directory as quoted provenance, not validation instructions.
